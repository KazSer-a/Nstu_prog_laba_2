# Лабораторная работа № 2. Алгоритмы и абстрактные структуры данных

Индивидуальный вариант 5. Программа представлена двумя консольными реализациями на C++17 и Go. Обе используют одинаковую нумерацию режимов и форматы входных данных.

## Сборка

Команды выполняются из корневого каталога проекта. Для реализации на C++ необходимы `make` и `g++` с поддержкой C++17. Для реализации на Go требуется Go 1.20 или новее.

| Команда | Назначение | Результат |
|---|---|---|
| `make cpp` или `make -C cpp` | Собрать реализацию на C++ | `cpp/laba2` |
| `make go` | Собрать реализацию на Go | `go/laba2` |
| `make` | Собрать обе реализации | `cpp/laba2` и `go/laba2` |
| `make clean` | Удалить исполняемые файлы сборки | Исходные файлы сохраняются |

## Запуск

В первом аргументе указывается номер режима. Данные можно ввести в терминале или перенаправить из файла. Например, `./cpp/laba2 3 < input.txt` запускает задачу об инопланетном геноме. Для версии на Go используется команда `./go/laba2 3 < input.txt`.

| Режим | Задание | Вариант | Результат |
|---:|---:|---|---|
| 1 | 1 | 5 | Возможность выполнить задачи с заданными зависимостями |
| 2 | 2 | Общее | Проверка наличия ключей с учётом вставок и удалений |
| 3 | 3 | 5 | Число совпадающих соседних пар символов |
| 4 | 4 | 5 | Число слов с ошибками в ударениях |
| 5 | 5 | 5 | Дерево поиска после восстановления ключей |
| 6 | 6.1 | 1 | Число записей, число проб и время вставки для двух методов |
| 7 | 6.2 | 5 | Число прямых и косвенных подчинённых каждого сотрудника |
| 8 | 7 | 1 | Значения, полученные запросами к LRU-кэшу |

Файловый режим множества запускается с аргументами `--file` и `--query`. Например, команда `./cpp/laba2 --file data/set.txt --query "SET_AT apple"` проверяет наличие элемента `apple`.

## Организация проекта

- `cpp/main.cpp` и `go/main.go` разбирают аргументы и передают ввод выбранному обработчику.
- `cpp/src/` содержит алгоритмы на C++. Их интерфейсы и используемые структуры находятся в `cpp/include/`.
- `go/` содержит реализацию тех же режимов на Go.
- `data/set.txt` служит начальным файлом данных для файлового режима множества.
