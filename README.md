# Лабораторная работа №2

Решения индивидуальных заданий на C++ и Go.

## Структура проекта

- `cpp/` — реализация на C++17.
- `go/` — реализация на Go 1.20.
- `docs/` — описание алгоритмов и тестовые примеры.

## Задания

| Модуль | Работа |
|---|---|
| `task_execution_order` | Проверка возможности выполнения задач с зависимостями (вариант 5, стек) |
| `set_commands` | АТД «Множество»: добавление, удаление и проверка наличия |
| `alien_genome` | Степень близости двух геномов (вариант 5) |
| `stress_check` | Проверка расстановки ударений (вариант 5) |
| `tree_recovery` | Восстановление BST после перестановки значений двух узлов (вариант 5) |
| `hash_methods` | Хеш-таблица с линейным апробированием и двойным хешированием (вариант 1 подзадания 6.1) |
| `employee_hierarchy` | Подсчёт числа подчинённых в иерархии (вариант 5 подзадания 6.2) |
| `lru_cache` | Кэш Least Recently Used (вариант 1) |

## Сборка

### C++

```sh
cd cpp
make
./laba2
```

Для запуска отдельного задания передайте его номер:

```sh
./laba2 1
```

### Go

```sh
cd go
go run . 
```

Для запуска отдельного задания:

```sh
go run . 1
```

## Форматы ввода

Форматы каждого модуля будут описаны в соответствующем разделе документации. При необходимости программа выводит подсказку о формате ввода.

## Примечание по заданию 5

В методических материалах не указан формат представления исходного дерева во входных данных. Для демонстрационной программы будет использована запись дерева по уровням: значения узлов разделяются пробелами, отсутствующий узел обозначается символом `#`. Алгоритм восстановления работает с уже построенным деревом и не меняет его структуру.

## Примечание по заданию 6

Подзадание 6.1 реализует оба требуемых метода разрешения коллизий: линейное апробирование и двойное хеширование. Подзадание 6.2 использует созданную хеш-таблицу для хранения связей сотрудников и менеджеров.

Все функции снабжаются короткими комментариями на русском языке.
