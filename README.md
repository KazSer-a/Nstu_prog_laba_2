# Лабораторная работа №2

Решения индивидуальных заданий на C++17 и Go 1.20.

## Структура
- `cpp/` — реализация на C++17.
- `go/` — реализация на Go 1.20.
- `docs/task_formats.md` — форматы ввода и примеры.

## Модули
1. `task_execution_order` — проверка зависимостей задач (вариант 5).
2. `set_commands` — АТД «Множество».
3. `alien_genome` — степень близости геномов (вариант 5).
4. `stress_check` — проверка ударений (вариант 5).
5. `tree_recovery` — восстановление BST после перестановки двух значений (вариант 5).
6. `hash_methods` — линейное апробирование и двойное хеширование (6.1, вариант 1).
7. `employee_hierarchy` — число подчинённых в иерархии (6.2, вариант 5).
8. `lru_cache` — LRU-кэш (вариант 1).

## Сборка и запуск
C++: `cd cpp && make && ./laba2 3`

Go: `cd go && go run . 3`

Вместо `3` указывается номер задания от 1 до 8. Форматы ввода приведены в `docs/task_formats.md`.

## Примечания
В методичке для задания 5 не указан формат представления дерева. Здесь принято соглашение: обход по уровням, пропущенный узел обозначается `#`. Это формат проекта, а не требование методички. Подзадание 6.2 использует открытую хеш-таблицу для хранения соответствий сотрудник–менеджер. Перед функциями размещены краткие комментарии на русском языке.
