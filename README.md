# Лабораторная работа №2

Решения индивидуальных вариантов на C++17 и Go 1.20.

## Задания

| № | Модуль | Работа |
|---|---|---|
| 1 | task_execution_order | Проверка порядка выполнения задач с зависимостями, вариант 5 |
| 2 | set_commands | АТД «Множество»: добавление, удаление, проверка наличия |
| 3 | alien_genome | Степень близости двух геномов, вариант 5 |
| 4 | stress_check | Контрольная по ударениям, вариант 5 |
| 5 | tree_recovery | Восстановление BST после перестановки значений двух узлов, вариант 5 |
| 6.1 | hash_methods | Линейное апробирование и двойное хеширование, вариант 1 |
| 6.2 | employee_hierarchy | Количество сотрудников в подчинении, вариант 5 |
| 7 | lru_cache | Кэш LRU, вариант 1 |

## Сборка

Из корня репозитория:

    make

Отдельно:

    make -C cpp
    cd go && go build -o laba2 .

## Запуск

Каждая задача запускается отдельным номером от 1 до 8. Ввод подаётся через стандартный ввод.

    ./cpp/laba2 3
    cd go && ./laba2 3

Для АТД «Множество» также поддержан командный интерфейс из методички:

    ./cpp/laba2 --file data/set.txt --query "SETADD apple"
    cd go && ./laba2 --file ../data/set.txt --query "SET_AT apple"

Файл содержит элементы множества, по одному на строку. SETADD и SETDEL изменяют файл, SET_AT печатает TRUE или FALSE.

## Проверка

    make test

Скрипт пересобирает обе версии, проверяет примеры задач 1–8, цикл в графе, отрицательные ключи хеш-таблицы и файловый интерфейс множества.

## Используемые структуры

Для решений переиспользованы адаптированные базовые структуры ЛР1: стек, динамический массив, двоичное дерево, множество и двусвязный список. Для подзадания 6.2 используется открытая хеш-таблица из подзадания 6.1.

## Соглашение по формату задания 5

Методичка не задаёт формат передачи исходного дерева. В проекте используется обход по уровням: значения разделяются пробелами, отсутствующий узел обозначается #. Это принятое соглашение для ввода, а не требование методички. При восстановлении меняются только значения двух узлов, связи дерева сохраняются.
