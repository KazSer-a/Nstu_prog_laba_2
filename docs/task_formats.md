# Форматы ввода и примеры

Запуск: `./cpp/laba2 <номер>` или `cd go && go run . <номер>`.

## 1. Порядок выполнения задач
Ввод: N M, N имён задач, затем M пар «задача предшественник».
```
3 2
A B C
A B
B C
```
Ответ: `Возможно`. При цикле — `Невозможно`.

## 2. АТД «Множество»
Ввод: Q, затем Q команд `SETADD x`, `SETDEL x`, `SET_AT x`.
```
5
SETADD cat
SET_AT cat
SETDEL cat
SET_AT cat
SET_AT dog
```
Вывод: TRUE, FALSE, FALSE.

## 3. Инопланетный геном
Ввод: две строки заглавных латинских букв.
```
ABBACAB BCABB
```
Ответ: 4. Повторы пар первого генома учитываются отдельно.

## 4. Контрольная по ударениям
Ввод: N, N слов словаря и одна строка текста.
```
4
cAnnot
cannOt
fOund
pAge
thE pAge cAnnot be fouNd
```
Ответ: 2.

## 5. Проверка дерева
В методичке формат дерева не задан. В проекте принят обход по уровням: пробел-разделённые значения, `#` для отсутствующего узла. Результат выводится в том же формате.
```
3 1 2 # # 4 #
```
Результат: `3 1 4 # # 2`.

## 6.1. Хеширование
Ввод: N, простая ёмкость M (M не менее 3), затем N целых ключей. Выводится число вставок и время для обоих методов.
```
6 11
10 21 32 43 54 65
```

## 6.2. Количество сотрудников
Ввод: N, затем N пар «сотрудник менеджер». Самостоятельное подчинение обозначает корневого менеджера.
```
5
A B
C B
D E
B E
E E
```
Вывод: A 0, B 2, C 0, D 0, E 4.

## 7. LRU-кэш
Ввод: ёмкость, Q, затем запросы SET x y или GET x.
```
2 8
SET 1 2
SET 2 3
SET 1 5
SET 4 5
SET 6 7
GET 4
SET 1 2
GET 3
```
Вывод: 5 -1.


## Методы хеширования: краткое сравнение

- **Линейное апробирование:** при занятой ячейке проверяется следующая. Плюс — простая реализация и последовательный доступ к памяти. Минус — первичная кластеризация: занятые области постепенно сливаются.
- **Двойное хеширование:** шаг пробирования вычисляется второй хеш-функцией. Плюс — обычно меньше кластеризация и более равномерный поиск свободной ячейки. Минус — вычисление второго хеша сложнее; размер таблицы выбран простым, чтобы последовательность проб могла охватить все ячейки.

Эмпирическое время зависит от набора ключей, размера таблицы, заполнения и среды выполнения. Для сравнения следует запускать оба метода на одном наборе входных ключей.
